# Photo-Cake Product Requirements

## Product Goal

Photo-Cake is a personal semi-automatic photography post-processing assistant.

It does not replace Lightroom. It prepares intelligent edits while keeping professional editing flexibility.

Core workflow:

```
RAW
 |
 v
Import
 |
 v
Culling
 |
 v
Grouping
 |
 v
Reference Style Analysis
 |
 v
Recipe Generation
 |
 v
XMP / Direct Export
```

## Core Principles

- Original RAW files are immutable.
- RAW + XMP is the primary workflow.
- Large intermediate files are not generated by default.
- Direct export is available on demand.
- Processing decisions are stored as editable Recipes.

## Lightroom Workflow

Primary output:

```
IMG.CR3
IMG.XMP
```

Photo-Cake generates Adobe compatible XMP sidecars so Lightroom can continue editing.

Do not initially implement:

- Lightroom plugin
- Lightroom catalog modification
- Lightroom database writing

## Intelligent Photo Workflow

### Culling

Analyze:

- Blur
- Focus quality
- Closed eyes
- Expression quality
- Duplicate photos
- Exposure problems

### Grouping

Photos should be grouped by:

- Event
- Location
- Lighting condition
- Scene type

Recipes are applied to groups, not blindly to all photos.

### Reference Style

Users can select preferred edited photos as references.

Flow:

```
Reference Photo
 |
 v
Style Analysis
 |
 v
Recipe
 |
 v
Apply to Similar Group
```

Analyze:

- Exposure style
- Color characteristics
- White balance
- Contrast
- Skin tone preference
- Lighting style

## Non-destructive Editing

Model:

```
RAW
 |
 v
Edit Graph
 |
 v
Recipe
 |
 +------+
 |      |
 v      v
XMP   Export
```

AI features should generate editable intent, not destructive replacements.

## Direct Export

Supported when requested:

- JPEG
- TIFF

Requirements:

- Preserve metadata
- Apply Recipe
- Keep RAW untouched

## Personal Workflow Goal

A user can process hundreds of RAW photos:

1. Import photos
2. Automatically identify quality and groups
3. Apply reference-based editing intent
4. Review results
5. Continue in Lightroom through XMP or export directly
